One funny line a hopeless tech support agent says to a desperate customer: he already turned it off and on again for them. It didn't work — but at least now they can both say they tried.

> I already turned it off and on again for you. It didn't work, but at least now we can both say we tried.

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 199 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
